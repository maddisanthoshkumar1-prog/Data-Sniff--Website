About DataSniff

DataSniff is a Python-based Log and Data Leak Detector developed to identify sensitive information from log files.

Project Objectives

  • Detect Email Addresses
  • Detect Passwords
  • Detect API Keys
  • Detect GitHub Tokens
  • Detect Phone Numbers
  • Detect IP Addresses
  • Reduce accidental data leakage

Technologies Used

Python, Flask, HTML, CSS, JavaScript, Regular Expressions (Regex), Pattern Matching and Entropy Analysis.
