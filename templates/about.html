About DataSniff

DataSniff is an automated Log and Sensitive Data Leak Detector designed to prevent inadvertent credential disclosure and sensitive information exposure in server logs.

🎯 Project Objectives

📧 Detect Disclosed Email Addresses
🔐 Detect Plaintext Passwords & Hashes
🔑 Identify API Keys & Cloud Credentials
🐙 Identify GitHub Personal Access Tokens
📱 Spot Phone Numbers & Contact Details
🌐 Identify Exposed IPv4 Addresses
⚠️ Detect High-Entropy Cryptographic Secrets
🛡️ Prevent Accidental Corporate Data Breaches

🛠️ Core Technologies & Algorithms

Built with robust, light-weight technologies for high performance and zero external leaks.

🐍 Python 3 🌶️ Flask Framework 🔍 Regular Expressions (Regex) 📊 Shannon Entropy Analysis 🛡️ Automated Data Masking ⚡ HTML5 & Modern CSS3 📈 Chart.js Data Visualizations 📑 JSON Audit Reports
